## 🚀 About

Full-stack developer at Holberton School with a product-first, ship-it mindset.
I build end-to-end: REST APIs on one side, clean reactive frontends on the other,
Docker and CI holding it all together.

- 🧱 **Backend** — Flask REST APIs, JWT auth, SQLAlchemy models, DB migrations
- 🎨 **Frontend** — React, Vue and Svelte (yes, I benchmarked them against each other)
- 🧪 **Habits** — tests first, small commits, readable structure, Conventional Commits
- 🌱 **Currently exploring** — agentic AI, LLM FinOps, task queues with Celery + Redis
